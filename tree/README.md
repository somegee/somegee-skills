# tree

Claude Code mod. 현재 프로젝트 폴더를 대화 오른쪽 창에 트리로 띄운다. **마우스로만** 쓴다.

```
 projects  ⎇ main ↑1  변경 3
 트리  변경 3  크기  ↻
 ┃ 파일 이름 검색 · Enter

 ▾ src/                                  •
›    app.ts                             ~M     ← 고른 줄
     열기  경로 복사  미리보기  바뀐 내용        ← 고른 줄 아래 버튼
     util.ts                             ?
 ▸ tests/
   README.md

 ─ 최근 작업                        비우기
 ~ app.ts  src
 ● 커밋 끝 · 3초 전
```

## 기능

- **트리**: 폴더를 누르면 펼치고 접는다. 파일·폴더를 누르면 고르고, 그 아래에 버튼 줄이 생긴다.
  - **열기**: 파일은 연결된 프로그램, 폴더는 탐색기(Finder)
  - **경로 복사**: 늘 **절대 경로**(윈도우는 `\` 구분)
  - **미리보기**(파일): 코드 색칠, 마크다운. 그림·문서·압축 파일은 안내만
  - **크기 그림**(폴더): 폴더 안 크기를 칸 그림 + 목록으로. 누르면 하위 폴더로 들어간다
  - **바뀐 내용**: git 이 아는 변경(diff). 새 파일은 '전부 추가'로 보여 준다
- **Claude 작업 표시**: 읽은 파일 보라, 쓴 파일 주황, 커밋한 파일 초록 — 8초 동안 이름 위로 밝은 띠가 물결처럼 흐른다(그동안만 1초에 2번 다시 그림).
  읽기는 Read·Grep·Glob 도구뿐 아니라 셸로 읽은 것도 잡는다: `cat`·`head`·`tail`·`sed -n`·`awk`·`grep`·`rg`·`jq`·`wc`·`diff` 등의 파일 인자와 `< 파일`, `grep -r`·`rg`·`find` 출력에 나온 파일(PowerShell 은 `Get-Content`·`Select-String`·`type`). 변수·와일드카드가 든 경로는 건너뛰고, 같은 명령이 쓴 파일은 주황(쓰기)으로 남는다.
  접힌 폴더 안이면 폴더 이름이 반짝인다. 보던 자리는 그대로 둔다(따라가기는 설정에서 켤 수 있음).
  셸 명령(cp·sed -i 등)으로 바꾼 파일도 명령 뒤 수정 시각으로 찾아 표시한다.
  Claude 가 만든 파일은 `+`, 고친 파일은 `~` 가 세션 동안 남고 아래 '최근 작업'에 모인다.
  Claude 가 돌린 git 명령(커밋·푸시 등)은 맨 아래 한 줄로 진행·결과를 보여 준다.
- **git 상태**: 오른쪽 끝 글자 `M` 고침 · `A` 추가 · `?` 새 파일 · `D` 지움 · `R` 이름 바꿈, 바뀐 것을 품은 폴더 `•`.
  머리줄에 브랜치와 원격보다 앞섬(↑)·뒤처짐(↓).
- **안쪽 저장소**: 루트 바로 아래와 펼친 폴더 바로 아래에 `.git` 이 있는 폴더도 따로 추적한다(최대 20개).
  그 폴더 이름 옆에 흐린 브랜치(`⎇ main ↑1`), 안쪽 파일에도 git 표시·변경 탭·바뀐 내용이 동작한다.
  루트가 저장소가 아니어도(여러 저장소를 모아 둔 폴더) 안쪽 저장소들은 추적된다.
- **변경 탭**: 바뀐 파일만 모아서 줄 수(+·−)와 함께.
- **크기 탭**: 고른 폴더(없으면 루트)의 크기 그림.
- **검색**: 파일 이름(입력 후 Enter).
- 창이 보이는 동안 3초마다 펼친 폴더를, 6초마다 git 을 다시 읽어 밖에서 바꾼 것도 보인다.

## 설치

```
/plugin marketplace add somegee/somegee-skills
/plugin install tree@somegee-skills
```

`/tree` 로 창을 열고 닫는다.

## 설정 (`/config` → tree)

| 항목 | 기본 | 설명 |
|---|---|---|
| 세션 시작 때 창 자동 열기 | 켬 | 끄면 `/tree` 로만 |
| Claude 가 만지는 파일 따라가기 | `off` | `writes` 쓰면 펼쳐 보여 줌 / `all` 읽을 때도 |
| 읽은 파일도 표시 | 켬 | Read·Grep·Glob 결과와 셸로 읽은 파일(cat·grep·rg…)을 보라색으로 |
| 숨길 이름 | `node_modules __pycache__ …` | `.git` 은 늘 숨김 |
| 최근 작업에 남길 파일 수 | 8 | 1~30 |

## 참고

- 터미널 화면만 그린다(데스크톱 앱 창은 아직 비어 있음).
